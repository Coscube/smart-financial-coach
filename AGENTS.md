# Smart Financial Coach Agent Overview

## Project Description

Smart Financial Coach is a React-based web application that serves as an intelligent financial planning platform for personalized money management and financial guidance.

## Standards

Avoid using excessive prop drilling; consider using context or state management libraries for better state handling.

Ensure all components are functional components and utilize React Hooks for state and lifecycle management.

## Skills

When working on this codebase, invoke the appropriate skill before starting work:

**React Components**: When writing, refactoring, or reviewing React components, invoke the 'react-development' skill first.

**E2E Tests**: When writing, updating, or debugging Playwright E2E tests, invoke the 'playwright-ux-tests' skill first.
